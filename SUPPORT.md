# Support

Thanks for using `eth-research`. This is a **research-only, offline** toolkit for developing and
evaluating trading *research* on historical ETH data — it is not a trading system and offers no
financial advice.

## Getting help

1. **Read the docs first** — most questions are answered under [`docs/`](docs/):
   - [`docs/INSTALLATION.md`](docs/INSTALLATION.md) — install and environment setup
   - [`docs/QUICKSTART.md`](docs/QUICKSTART.md) — end-to-end first run
   - [`docs/PUBLIC_API.md`](docs/PUBLIC_API.md) — the stable public API
   - [`docs/CUSTOM_STRATEGIES.md`](docs/CUSTOM_STRATEGIES.md) — writing your own strategy
   - [`docs/V1_LIMITATIONS.md`](docs/V1_LIMITATIONS.md) — the honest boundary of what this does and does not do
2. **Search existing issues** — your question may already be answered.
3. **Open an issue** — for bugs and feature requests, use the repository's issue tracker with a
   minimal reproduction (version/commit, inputs, expected vs actual).

## What support does *not* cover

- Trading, investment, or financial advice.
- Live trading, exchange/wallet integration, or anything that places orders or touches funds — the
  project deliberately has none of this and will not add it.
- Interpreting whether a strategy is "good"; the tools make backtests *auditable and reproducible*,
  not profitable.

## Security

For suspected vulnerabilities, do **not** open a public issue — see [`SECURITY.md`](SECURITY.md).
