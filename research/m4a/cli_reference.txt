usage: eth-research [-h]
                    {version,doctor,demo,dataset,backtest,result,receipt} ...

Offline ETH research: validate data, run backtests, verify artifacts.

positional arguments:
  {version,doctor,demo,dataset,backtest,result,receipt}
    version             print the package and API versions
    doctor              check the installation and run a synthetic self-test
    demo                generate a runnable offline demo
    dataset             validate / build / inspect OHLCV datasets
    backtest            run a backtest from a config
    result              verify a result artifact
    receipt             verify a run receipt

options:
  -h, --help            show this help message and exit


usage: eth-research version [-h] [--json]

options:
  -h, --help  show this help message and exit
  --json      emit deterministic JSON output

usage: eth-research demo generate [-h] --output OUTPUT [--periods PERIODS]
                                  [--seed SEED] [--overwrite] [--json]
